# Paper Types in tm2+

## High-Impact Papers (Q1 Target)

### Intellectual Structure

* Subpackage: `intellectual/`
* Key tables and plots: co-citation clusters, historiograph, main path, core references by cluster, dual-map overlay
* Contribution: reconstructs the knowledge base and intellectual lineage of the field

### Thematic Structure

* Subpackage: `thematic/`
* Key tables and plots: co-occurrence network, correlation map, thematic map, cluster descriptors, TF-IDF tables
* Contribution: defines the conceptual architecture of the field

### Temporal Evolution

* Subpackage: `dynamics/`
* Key tables and plots: thematic evolution (Sankey/alluvial), time-sliced clusters, lifecycle plots, long-term trends
* Contribution: explains how themes evolve across periods

### Frontier / Emergence

* Subpackage: `emergence/`
* Key tables and plots: burst detection, emergence rankings, acceleration plots, recent growth analysis, union-of-signals table
* Contribution: identifies emerging topics and current research frontiers

### Structural Gaps / Novelty

* Subpackage: `novelty/`
* Key tables and plots: structural variation analysis (SVA), white-space maps, missing-link maps, bridging-node tables
* Contribution: identifies research gaps and opportunities for future work

## Low-Impact Papers (Q4 Target)

### Performance Mapping

* Subpackage: `performance/`
* Key tables and plots: annual production, top authors/institutions/countries, Bradford zones, citation indicators
* Contribution: descriptive overview of productivity and impact

### Social Structure

* Subpackage: `social/`
* Key tables and plots: co-authorship networks, country collaboration maps, institutional collaboration tables
* Contribution: describes collaboration patterns in the field

### Comparative Mapping

* Subpackage: `comparative/`
* Key tables and plots: side-by-side maps, overlap tables, segment comparisons
* Contribution: compares structures across datasets, regions, or periods

### Validation / Robustness

* Subpackage: `validation/`
* Key tables and plots: sensitivity analysis, normalization comparisons, cluster stability tables
* Contribution: evaluates robustness and reliability of results

### Tech Mining / Applied Intelligence

* Subpackage: `techmining/`
* Key tables and plots: technology clusters, trend radars, application maps, portfolio tables
* Contribution: translates scientific structure into applied and technological insights

### Systematic Review Synthesis

* Subpackage: `review/`
* Key tables and plots: PRISMA diagram, inclusion/exclusion tables, corpus description, integrated summary maps
* Contribution: provides a reproducible systematic review supported by bibliometric evidence
